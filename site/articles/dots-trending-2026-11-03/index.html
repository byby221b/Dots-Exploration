🔧 开源热榜

vercel-labs/agent-desktop

⭐+2,275 · Rust · GitHub stars today（非北京时间自然日）

把操作系统提供的界面控件树转成带引用的 JSON，代理据此点击或输入，再取新快照核验结果；支持 macOS、Windows 和 Linux。

它用快照标识管理控件引用，界面变化后要求重新定位，适合研究桌面代理如何减少点错对象，以及怎样与用户的手动操作配合。

D4Vinci/Scrapling

⭐+706 · Python · GitHub stars today（非北京时间自然日）

将网页请求、浏览器渲染、解析和并发采集整合到一个 Python 框架，也提供供 AI 代理调用的 MCP 接口。

可重点学习可复用会话、暂停恢复和结构化导出，适合把零散采集脚本整理成持续运行的流程；使用时需遵守目标网站的访问规则。

hyprwm/Hyprland

⭐+509 · C++ · GitHub stars today（非北京时间自然日）

面向 Linux 的桌面合成器，负责把应用窗口组织、绘制到屏幕上；它支持自动平铺窗口，也保留特效和多种布局。

配置保存即可重载，程序还能通过进程间通信接口控制桌面。窗口规则、插件和按工作区切换布局，适合定制自己的操作环境。

FlexAttention：把注意力规则写成可组合函数

深度精选·2025-11-14

从两个小函数入手：一个修改注意力分数，一个规定哪些位置可以互相关注，再将规则组合成文档隔离、前缀可见等模式。

教程继续把规则转成分块结构，跳过整块无效计算，并给出 CuTe DSL 与 PyTorch 代码。适合已有注意力基础、想编写自定义内核的读者。

Mamba-3：从连续状态方程推到高效递推

深度精选·2026-03-16

从随时间变化的状态方程出发，逐步推导计算机执行的离散更新，再用旋转表示复数状态，解释模型怎样跟踪奇偶等变化。

后半篇连接到实现：把旋转移到输入和输出，并用多路输入、输出提高计算密度。适合有线性代数基础、想看清表达能力与访存取舍的读者。

整数除法优化：从误差界推到 CPU 指令

从数学界限、C++ 到汇编和实测逐层讲解；收益随除数、编译器和 CPU 改变，文中也展示了反而更慢的情形。

新文·2026-11-02 · HN 158 分／107 条评论（采集时）

文章解释为何转向 Trino 与自建 HogLake，适合学习云数仓如何划分计算、存储和元数据职责；这些取舍对应其具体生产负载。

Cloudflare：只重建受影响的 DNS 数据 讨论

新文·2026-11-02 · HN 138 分／47 条评论（采集时）

修改一条 DNS 记录时，先判断需要重建哪些数据，再合并同一区域的待办事件，减少重复读取和整区重建。

文章详解局部更新与消息确认如何保持一致。团队报告峰值内存下降 85%，构建中位延迟约从 7.7 秒降至 3.3 秒；该计时止于存储写入，后续全球分发另计。

μ 子催化聚变：发电之外，奇异原子还有什么价值？

新文·2026-11-02 · George Musser

用更重的 μ 子替代电子，原子会缩小，让氢核更容易靠近并聚变；文章由此带读者进入奇异原子的研究。

这项研究尚未实现能量收支平衡，而奇异原子本身能帮助研究强电场和原子核结构。看点是可检验的基础物理问题，以及实验如何拓展研究工具。
