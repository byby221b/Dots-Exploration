🔧 开源热榜

incoai/splash

⭐+52 · GitHub C++ 日榜

把支持的量化模型跑在 Apple Silicon 上，用 Metal 内核、DFlash 2 投机解码和前缀缓存提高本机推理效率。
有本地 API 和自动内存规划，可用来做单机推理实验；官方目前要求 Apple M3 或更新机型与 macOS 26.4 或更新版本。

apache/airflow

⭐+24 · GitHub Python 日榜

把数据准备、训练、评估和部署写成带依赖的任务图，由调度器安排到多个工作进程执行，并在界面追踪进度和失败。
适合有稳定骨架、反复运行的实验流程，大批量数据留在外部存储，任务之间只传位置、版本或指标等元数据。

t8y2/dbx

⭐+117 · GitHub Rust 日榜

把 PostgreSQL、SQLite、DuckDB 等数据库接入同一个跨平台界面，提供查询编辑、结构浏览与结果表格。
处理大结果集时，虚拟滚动避免一次绘制所有行；需要修改数据时，也可以先预览将要提交的 SQL。

🧠 AI/模型

Ternary Bonsai 2.5 27B：低比特权重下的工具调用

Hugging Face 热门第 6

它在 Qwen3.8-27B 架构上使用三值权重，模型卡给出的 PTQ1_0 文件约为 5.93 GB、平均每权重 1.76 bit。
这一版着重改善工具调用与编码，部分变体还附带多 token 预测头；权重文件大小不包含运行时缓存，端侧部署要另算。

Nemotron Labs Image：用视觉 token 自回归生成图像

Hugging Face 热门第 10

NVIDIA 把图像拆成离散视觉 token 再自回归生成，模型卡称图像生成器约 30B 总参数、3B 激活参数。
本次公开的是栅格图像生成器和配套分词器，不是完整的可编辑网页或图表生成框架；权重适用 NVIDIA 非商业研究与评估许可。

每个格子只看邻居，怎么拼出一张会自我修补的图？

深度精选·2020-02-11·Distill

让像素格共享同一套小网络，每次只根据附近格子的状态更新，从单点逐步画出完整图案。
作者对比了从单点训练、重用中间状态、以及训练时随机擦除图案三种做法；网页上可亲手擦掉一块，看它怎样重新长回来。

🔥 热议话题

Minipg：把 PostgreSQL 装进一个可执行文件

HN 288 分／44 条评论（抓取时累计）；项目页未标发布日期

Minipg 把 PostgreSQL 和运行环境打包，数据与配置保存在一个目录里；有命令需要时才启动服务，空闲时会自动停止。
它让本地试验和 CI 少一步搭建工作，但作者明确提醒项目还早，部分环境性能低于原生 PostgreSQL，不宜保存无法重建的数据。

一本 Unix 教材，为什么靠复印本流传近二十年？

HN 272 分／66 条评论（抓取时累计）；原文 2026-11-25

漫画重述了 John Lions 为讲解 Unix 第六版内核写下注释的经过，以及后来的许可证限制怎样改变了它在课堂上的流通。
从早期讲义到 1996 年正式出版，这段历史也解释了为什么读真实的内核代码曾是学习操作系统的一种难得机会。

Nextcloud Office 有了能离线编辑的桌面版

HN 395 分／201 条评论（抓取时累计）；原文 2026-11-13

Nextcloud 推出的桌面套件可以在本地编辑文档、表格和演示文稿；连接到 Nextcloud Hub 后，也能和同事共同编辑线上文件。
它可以使用电脑上安装的字体，但协作者缺少同一字体时会看到替代字体，跨设备排版仍值得检查。
