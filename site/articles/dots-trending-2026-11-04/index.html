max-sixty/worktrunk

⭐+438 · Rust · GitHub stars today（非北京时间自然日）

给并行编码代理各开一个 Git 工作目录，避免改动互相踩踏。

JustVugg/colibri

⭐+802 · C · GitHub stars today（非北京时间自然日）

面向每次只调用部分专家分支的混合专家模型（MoE），将常用专家留在显存，其余放内存或按需从磁盘读取，支持运行超出显存容量的模型。

这个 C 引擎把缓存、预取与计算重叠，并提供 CUDA、Vulkan 后端。显存需求降低后，磁盘容量和读取带宽仍是重要条件。

floci-io/floci

⭐+482 · Java · GitHub stars today（非北京时间自然日）

它提供存储、队列等兼容接口，数据库与 Lambda 等通过 Docker 执行，减少测试对云账户的依赖；具体 API 仍应核对支持范围。
