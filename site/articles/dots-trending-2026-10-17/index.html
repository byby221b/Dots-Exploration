⭐+281 · Python · GitHub stars today

适合研究让代理调用现有软件的方法；覆盖范围取决于具体适配器，仍需安装相应软件并验证真实输出。

android/skills

xerj-org/xerj

⭐+1,648 · Rust · GitHub stars today

给本地代码、文档和日志建立索引，让代理按相关片段及文件位置检索，减少逐个文件读取，并提供 Elasticsearch 兼容接口。
适合探索代码检索与参考实现复用；性能宣传需另行复测，关闭认证的本地模式不应直接暴露到不可信网络。

🧠 AI/模型

Muse Spark Open：多模态稀疏模型的公开权重

HF 当前热榜 · 模型卡发布日期2026-10-15

用混合专家分担计算，支持文本、图像、音频和视频输入及文本输出；模型卡列出总参数8160亿、每个词元激活约420亿。
适合研究多模态代理和大模型部署；稀疏激活不等于小内存占用，量化版仍需很大显存，下载和使用须遵循访问与许可要求。

Zephon：换一组 GPU，训练数据顺序仍能一致

PyTorch · 2026-10-16

把有状态的数据决策与并行处理分开，再用固定逻辑通道组织样本，使在线分词、打包和混合在改变 GPU 数量后仍生成相同全局批次。
适合检查数据消融是否混入资源分配的影响；恢复时须保持数据配方和全局批量等设置，数据一致也不保证浮点计算逐位相同。

负载均衡：把请求分给谁，队列会怎样变化？

深度精选·2023-04-10 · Sam Rose

用可调动画追踪请求怎样进入队列，逐步比较轮询、最少连接与结合延迟的分配办法，呈现吞吐、尾延迟和丢请求的取舍。
适合建立服务调度直觉；演示省略网络延迟等真实条件，算法优劣仍需用自己的负载验证。
