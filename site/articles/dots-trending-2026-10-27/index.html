NVIDIA/SkillSpector

⭐+214 · Python · GitHub stars today（非北京时间自然日）

在安装代理技能前，先用静态规则扫描代码与提示词，再按需调用语言模型判断语义风险，覆盖提示注入、数据外传等问题。
可输出 JSON、Markdown 和 SARIF 报告，并用基线压低重复告警，适合接入安装审核；扫描通过不等于安全保证。

makecindy/cindy

⭐+1,296 · TypeScript · GitHub stars today（非北京时间自然日）

把 Claude Code、Codex 等执行框架放进同一客户端，切换模型时保留工作区、记忆和工具，也支持多代理分工。
适合研究跨框架的任务编排；公开仓库仅含桌面、移动客户端与共享包，后端服务另行维护，并非整套系统都已开源。

适合把本地文档处理接入代理工作流；当前版本仍把 PDF 转 Office 等能力列在路线图，接入云端代理也须另查数据流向。
