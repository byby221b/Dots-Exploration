🔧 开源热榜

NVIDIA/OpenShell

⭐+1,281 · Rust

为自主智能体提供可控运行环境，对文件访问、系统调用与网络实施隔离，并限制凭证的使用范围。

适合需要运行代理代码又希望约束权限的场景；仍需配置容器或虚拟化，并审查安全策略。

debpalash/VoiceStudio

⭐+3,483 · Python

把声音克隆、视频配音、转写与有声书制作整合到本地桌面，提供本地 API 和 MCP 接口。

适合搭建私有语音工作流；硬件需求取决于所选引擎，项目与模型许可需分别检查，克隆声音应取得授权。

mvschwarz/openrig

⭐+624 · TypeScript

用 YAML 编排 Claude Code 与 Codex 协作团队，通过 tmux 提供消息通信、拓扑查看和快照恢复。

适合探索持续运行的编码代理；启动会涉及工作区信任与可执行钩子，采用前应审查配置，原生 Windows 尚不支持。

🧠 AI/模型

Edge0/Audio8-ASR-Infinite

流式语音识别 · 预览版

面向中英实时转写，以可选音频节拍和滚动 KV 缓存处理持续音频，重点是长时流式运行。

值得读的是推导路线及假设边界：作者依赖多项近似作启发式分析，并未证明 Shampoo 在实际训练中必然更差。

适合已有 Transformer 基础、想把模型设计与算力预算连起来的人；实践主线偏 TPU/JAX，另有 GPU 专章。

深度精选 · 2026-03-30 · Tri Dao

适合有矩阵分析、优化和 GPU 基础的人；收益依赖矩阵形状与硬件，优化器本身提速不等于整段训练同比提速。

系统作业覆盖 Triton FlashAttention 与分布式训练；需要 Python、PyTorch、线代和概率基础，代码与算力投入较高。
