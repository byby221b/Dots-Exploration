⭐+83 · Python · GitHub Today

从12个采样点，推到离散时间傅里叶变换

深度精选 · 2026-09-19 · Eli Bendersky

图像扩散为何从轮廓走向细节？从频谱推到代码

深度精选 · 2024-09-02 · Sander Dieleman

从自然图像的频谱出发，推导高斯噪声为何先淹没高频细节，并用配套 Python notebook 把去噪解释成近似的频域自回归。

作者也用音频反例划清边界：这是依赖图像统计规律的近似，不是所有扩散模型的恒等式。
