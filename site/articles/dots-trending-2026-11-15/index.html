🔧 开源热榜

ChromeDevTools/chrome-devtools-mcp

⭐+664 · TypeScript · GitHub stars today（非北京时间自然日）

让编码代理直接检查真实 Chrome 页面，读取网络请求、控制台与性能轨迹，把“页面哪里慢、哪里出错”接到调试流程中。

提供工具接口和命令行；连接后会向代理暴露浏览器内容，使用统计默认开启，接入前需检查数据范围与相关配置。

louislam/uptime-kuma

⭐+430 · JavaScript · GitHub stars today（非北京时间自然日）

自托管监控工具可定期检查网页、端口、域名记录和容器状态，再通过通知与状态页展示故障，适合集中观察小型服务。

支持证书信息和多种通知渠道；官方安装默认监听全部网络接口，持久化存储也不支持 NFS 网络文件系统，部署时需核对。

Tencent/LoopForge

⭐+33 · Go · GitHub stars today（非北京时间自然日）

把编码代理、脚本检查和人工审批串成可重用流程，在自托管工作区记录各阶段的产物、状态与重试路径。

适合研究团队怎样组织代理交付；默认 Docker 方案面向可信团队，访问主机 Docker 服务的权限不能当作不可信多租户隔离。

🧠 AI/模型

Idol：从一张物体图生成可转动的三维表示

HF trendingScore 当前第 6 · Apache 2.0 · 现有模型

模型先去除背景、裁切物体，再生成许多带位置和颜色的三维高斯点，导出可在查看器中转动的 PLY 文件，包含输入图没展示的侧面。

适合研究图像到三维的生成流程；未见部分由模型补全，不能当实测几何。运行还依赖两款需先同意访问条款的图像编码模型。

Log-Sum-Exp：怎样让概率计算避开数值溢出？

深度精选·2020-02-09 · Gregory Gundersen

直接对很大的分数取指数会溢出，极小值又可能被舍成零。文章推导先减去最大值、再做指数求和与归一化，说明为何结果保持等价。

配有 NumPy 例子和公式，适合有基础概率与 Python 经验的读者理解数值稳定性；极小概率仍可能舍入为零，实作宜采用成熟库。

ggml 1.0.0：清理旧接口，推进多后端推理

发布 2026-11-13 · HN 24 小时内提交

张量计算库这一版移除废弃接口，并改进多种硬件后端的矩阵运算、注意力和专家模型执行，也减少调度器搬运未使用输入的开销。

适合跟踪本地推理底层如何演进；旧操作被删除，远程调用协议也有升级，集成方需检查兼容性，不能仅凭 1.0 版本号假定无缝替换。

PyPI 新安全页：看清软件包从哪里构建和发布

原文 2026-11-06 · HN 24 小时内提交

新界面集中展示发布文件的来源证明，并标出证明缺失、构建来源不一致或相较旧版发生变化，帮助安装者追查供应链。

来源证明回答的是文件从哪里来；没有证明不自动等于恶意，有证明也不能代替代码审查。文章解释了各类提示应怎样结合项目历史判断。

🔬 科学/人文

生命起源的新问题：化学系统怎样开始持续演化？

2026-11-12 · Quanta · Yasemin Saplakoglu

这篇长报道把此前几种“哪类分子先出现”的假说放回共同问题：分子反应怎样保存信息、持续繁殖，并形成能独立演化的系统。

它串起祖先重建、化学实验与合成细胞研究；出现生长或分裂还不等于重建生命，部分成果仍是预印本或未发表工作。
