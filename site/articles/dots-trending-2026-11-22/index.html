🧠 AI/模型

离散傅里叶变换：为什么 N 个采样点只需要 N 个频点？

2026-11-21（作者当地日期）·Eli Bendersky

把有限的采样看作一个周期，文章用彼此正交的旋转基底推导 DFT 和逆变换，再用 NumPy 演示怎样重建采样值。
把观测窗口截短后，即使采样值仍可准确重建，信号的频率成分也会散到邻近频点，形成频谱泄漏。

把 CUDA 算子调优经验迁移到 Apple Silicon

深度精选·2026-07-29·BAIR

K-Search 把 CUDA 算子的分块、归约和同步经验转写成 Metal 上的实现约束，再生成候选代码并在真机上测量。
作者在 M1 Max 的 Mamba-370M 实验中，以并行扫描提高了整段输入的处理吞吐，最高约为社区 mlx-lm 的 20 倍；逐 token 解码没有同量级提升。

长对话压缩后，怎么检验模型记住了什么？

深度精选·2026-07-26·BAIR

ABBEL 用一段不断更新的文字状态代替完整对话，并检查模型能否从这段状态还原刚观察到的信息，把“记住什么”变成训练信号。
作者在协作编程基准上报告，训练缩小了压缩策略与完整上下文的表现差距，同时降低了峰值上下文长度。

Lean 社区核验标准黎曼猜想的形式化证明

HN 810 分／647 条评论（抓取时累计）；原文 2026-11-21

Lean 与 Mathlib 社区联合声明称，Alpöge 的证明所用命题与 Mathlib 的标准陈述一致：黎曼 ζ 函数的非平凡零点实部均为 1/2。
多种独立实现的检查器通过了同一份导出的证明。这份联合声明核验的是标准黎曼猜想，不宜外推到更一般的 L 函数。

下载速度少了四分之三，问题出在显示器的 USB 集线器？

HN 473 分／227 条评论（抓取时累计）；原文 2026-11-15

作者发现同一网卡直连电脑能跑到约 2.2 Gbps，经显示器集线器却降到约 600 Mbps，于是对照驱动、流量控制与网卡的发包参数逐一排查。
在这套设备上，旧网卡通过集线器时来不及把收到的数据送走；更换支持更大突发传输的网卡后，高速下载不再丢帧。

gopgext：用 Go 编写 PostgreSQL 扩展

HN 117 分／20 条评论（抓取时累计）；项目页未标发布日期

这个实验项目以 TinyGo 编译 Go 代码，并生成 C 桥接与 SQL 安装脚本，让标注过的函数可以直接在 PostgreSQL 中调用。
它也尝试支持触发器、聚合和索引扩展；由于生成代码会在数据库进程内部运行，作者明确建议暂勿用于生产。
