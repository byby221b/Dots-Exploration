🔧 开源热榜

Donchitos/Claude-Code-Game-Studios

⭐+742 · Shell · GitHub stars today（非北京时间自然日）

这套 Claude Code 模板把游戏开发拆为设计、程序、测试与发布等角色，并提供 Godot、Unity 和 Unreal 引擎相关工作流。

用户可以选择不同流程强度，按项目需要保留或减少文档与审查步骤；它提供的是代理协作配置，不是已验证能独立完成游戏的开发团队。

pingdotgg/t3code

⭐+1,148 · TypeScript · GitHub stars today（非北京时间自然日）

T3 Code 为已安装在电脑上的编码代理提供统一操作界面，可从手机、网页或桌面应用控制不同工具。

它复用 Claude Code、Codex 等工具的现有账号与认证，适合需要跨设备管理代理任务的人；使用前仍须安装并登录至少一种受支持工具。

它进一步把局部信息传播连到图上的频谱表示，说明节点重编号为何只应相应重排节点输出，以及全局谱方法的计算成本和跨图迁移限制；适合具备矩阵运算基础的读者。

A friendly introduction to machine learning compilers and optimizers

随后比较手写优化规则与自动调优的取舍，适合建立性能排查的基本框架；文中的工具生态和性能数字属于 2021 年背景，不应当作今天的选型清单。

文章用内存块图讲解两者如何共用空间、搬移和淘汰；特定缓存压力实验显示的收益，不能推广成通用吞吐加速。

Jepsen: ParticleDB 1.1.4 讨论

🔬 科学/人文

What Crystals Older Than the Sun Reveal About the Start of the Solar System

往期佳作 · 2026-03-02 · James Dinneen

陨石中比太阳更古老的微小晶粒保存着恒星物质的化学线索，可帮助检验太阳系究竟由超新星爆炸，还是大质量恒星吹出的恒星风触发形成。

铝与铁同位素的相对丰度是区分两种解释的关键，但测量和模型仍有争议；寻找特定来源的晶粒是在约束假说，还不是确定了太阳系的唯一诞生过程。
