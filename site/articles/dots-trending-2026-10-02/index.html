🔧 开源热榜

tile-ai/tilelang

⭐+163 · Python · GitHub Today

用类 Python 语法编写矩阵乘法、注意力等高性能算子，底层编译器处理布局和流水线。

9月30日新增昇腾950原生后端；适合沿示例把算法落到硬件，也可对照各后端的支持边界。

mksglu/context-mode

⭐+362 · TypeScript · GitHub Today

把工具返回的原始数据留在子进程里，只把筛选结果送入上下文；再用 SQLite 全文检索找回会话事件。

适合排查长任务为何很快“失忆”，但其执行工具仍继承进程权限，不能当作完整的系统安全沙箱。

Friedrich-M/UniMate

⭐+217 · Python · GitHub Today

用统一模型根据文字生成不同骨架的动作，无须为每种骨架重新训练。

训练代码和预览权重已公开；作者也直说不少骨架仍会失败，全新骨架的预处理管线尚待补齐，适合研究而非直接当成品使用。

🧠 AI/模型

几何建模配合表格、公式的内容结构解耦，是比单看跑分更值得读的部分；模型卡提供代码与多组自报评测。

Contrastive-LM/CLM-v0.1-8B

HF 当前热榜 · 非今日首发

冻结 Qwen3-8B，分别把当前状态与候选动作映射成向量，用对比学习训练打分，并复用候选向量。

适合研究工具选择和候选排序：它只评估给定选项，不生成答案，输出概率也取决于候选集合。

TLX 优化变长 Flash Attention：从瓶颈定位到 Blackwell 内核

2026-10-01

把变长注意力的负载不均、归约争用与寄存器溢出逐项落到 TLX 代码和性能验证，提供可跟做的优化过程。

作者在 B200、bf16 的 GEM 形状上报告前向约快 13%、反向约快 50%，对比限于今年5月版 FA4。

UnigramLM：把分词的概率模型一直推到 SentencePiece

深度精选 · 2026-04-27

从一个字符串有哪些合法切分讲起，逐步推导分词格、前向后向与 EM 更新，再把词表剪枝接到 SentencePiece 实现。

尤其值得看数学模型与工程近似在哪些地方分岔，适合补齐 BPE 之外的分词直觉。

NVFP4 GEMM 两篇连读：从布局推导到逐级优化

深度精选 · 2026-06-20、2026-08-09

先比较两类 Blackwell 的指令与内存模型，再推导缩放因子的线程布局，把 BF16 内核改成 NVFP4。

续篇逐级处理调度、流水线和缓存问题，附源码与基准，也诚实保留无效优化，适合沿着推导动手复现。
续篇：逐级优化与性能测试

从最小二乘理解密度比与 KL 估计

深度精选 · 2026-09-25

从指数均值的方差为何失控出发，把密度比与 KL 估计改写为一族最小二乘问题，再用广义特征分解求解。

推导后接高维分析和模拟实验，说明何时降低方差值得引入偏差，也交代计算成本与适用边界。

🔥 热议话题

Pi 1.0：可扩展编码代理进入稳定版

HN · 过去24小时提交

在保持小型核心的基础上加入按需加载工具、虚拟模型扩展和原生 Codemode，方便把不同模型与工具接到同一工作流。

同时推出面向长任务的实验性 Pi Durable；适合研究代理编排，而非只比较单次代码生成。

Clef：把受约束的决策交给专用模型

HN · 过去24小时提交

输入上下文与候选答案，模型直接并行给候选打分，无需逐词生成中间文字；适合分类、工单路由和工具选择。

Cloudflare 开放 Clef 权重，并推出人工协助的强化学习微调服务，自助平台仍在规划中。

turbopuffer：为何要让向量索引退居次级索引

HN · 过去24小时提交

把文档主键绑定到向量聚类，向量重排就会牵动属性和全文索引，也限制聚合扫描的数据块大小。

这篇架构复盘解释存储、写入与计算上的代价，以及 v3 如何解耦文档布局；性能优化和生产部署仍在推进。
