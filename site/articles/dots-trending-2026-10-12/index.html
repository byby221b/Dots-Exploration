🔧 开源热榜

lyogavin/airllm

⭐+548 · Jupyter Notebook · GitHub Today

每次只将一层权重搬入显存，用磁盘与主机内存换取大模型在小显存设备上运行的机会，也提供冻结底座、训练适配器的路径。

适合研究存储与计算的取舍；瓶颈可能转到权重加载，需留足磁盘空间，显存占用低并不等于生成速度快。

bilawalsidhu/gods-eye-view

⭐+886 · JavaScript · GitHub Today

把航班、船舶、卫星、天气等公开信号放进同一个三维地球，各数据层独立组织，并支持语音查询与场景编排。

可参考多源地理数据的整合方式；交通层含模拟数据，部分信号有延迟或估计误差，不能用于导航或应急决策。

chrislgarry/Apollo-11

⭐+466 · Assembly · GitHub Today

保存阿波罗11号指令舱与登月舱制导计算机的汇编源码，数字化文本可与原始扫描件交叉核对。

适合做一次历史软件阅读：沿模块、注释和接口观察早期航天程序如何组织；编译与仿真需配合另行链接的 Virtual AGC 工具。

🧠 AI/模型

EMA Lightning：小模型怎样完成流式语音合成

HF 当前热榜 · 非今日首发

用字母时长预测对齐文本与语音，再经四步生成和分窗解码输出音频；声学模型加声码器共860万参数，支持多请求合批。

模型卡公开结构、评测设置和限制，适合研究小模型语音部署；仅支持土耳其语与单一音色，不提供声音克隆，速度数据依赖测试硬件。

Clef：把多个结构化问题放在一次前向计算里

HF 当前热榜 · 非今日首发

在270亿参数多模态底座上增加联合打分头，让文本、图片或视频中的证据分别流向多个问题，一次输出各允许选项的概率。

可研究分类、工具路由和结构化决策，省去自由文本解析；模型卡示例在单张 H200 上测试，输出合法选项仍不保证判断正确。

word2vec 学到了什么？沿训练过程追踪词向量的方向

深度精选 · 2025-06-28 · 作者原文

从词频与共现概率构造目标矩阵，解释词向量怎样在训练中逐步增加有效维度，并用图示对照理论与实验。

解析结果依赖小初始化、目标近似等条件，适合学习表示形成的机制；不能直接把全部词向量训练等同于主成分分析。

Blackwell 动态调度：让空闲计算单元接手剩余矩阵块

深度精选 · 2026-05-09 · Colfax Research

先用分组矩阵乘解释负载不均，再逐段读 CuTe DSL 代码：已启动的线程块集群接手尚未启动的工作，减少等待。

附 B200 实测与调度时间线，适合学习内核负载均衡；CLC 依赖 Blackwell，均匀任务下并不总胜过静态调度。

🔥 热议话题

让陌生人照着 README 安装：找出作者看不见的缺步骤

HN过去24小时提交 · 原文2026-10-11

作者邀请用户共享屏幕、边安装边说出困惑，每次测试后修改说明，再交给下一位继续尝试。

错链接、隐藏文件改名和权限差异由此暴露。文章提供一种可复用的文档测试方法；这是项目实践记录，没有把少量参与者的反馈当作普遍效果证明。

Valen 借用检查：让编译器记住引用指向哪里

HN过去24小时提交 · 原文2026-10-11

用对象路径描述引用的指向，并在容器被修改后标记可能失效的内部引用，从而在编译时阻止继续使用。

作者用小段代码解释如何允许更灵活的共享修改，适合理解内存安全设计；部分语法简化与类型稳定性例外尚未实现，性能展望仍待实测验证。

🔬 科学/人文

基因怎样起作用？把 DNA 序列放回三维细胞环境

往期佳作·2026-06-18 · Quanta

远处的调控片段可借 DNA 折叠接近基因，多种蛋白和细胞环境再共同影响它是否被读取。

文章串起三维结构、化学标记与 RNA 调控，帮助理解仅凭序列预测功能的难处；这不等于证明 AI 无法学习这些关系。

从田边的一条草带，理解土地伦理怎样落地

往期佳作·2026-09-24 · Aeon

作者从农田留草防蚀、粪肥回归土壤讲起，把土地保护连到农户的成本、经验和邻里关系。

再以野牛吃草后为野花腾出空间为例，讨论为何产量之外还要考虑生态多样性；这是生态随笔，不是通用农业处方。
