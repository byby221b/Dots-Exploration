🔧 开源热榜

expo/skills

⭐+38 · Shell · GitHub stars today（非北京时间自然日）

Expo 官方把应用构建、升级、调试及 Expo 应用服务（EAS）的部署流程整理为编码代理可调用的技能。

框架技能与付费服务相关技能分开标注，适合希望让代理遵循平台约束、而非凭通用经验编写移动应用的开发者。

lightpanda-io/browser

⭐+626 · Zig · GitHub stars today（非北京时间自然日）

Lightpanda 是用 Zig 从头实现、面向自动化与 AI 代理的无头浏览器，并非 Chromium 分支。

项目提供 Chrome 调试协议（CDP）接入和页面内容导出，适合研究网页操作的资源开销；其性能数字来自项目自测，不宜直接外推到所有站点。

🧠 AI/模型

Unlimited-OCR-2

模型精选 · 首发 2026-10-27 · 当前 HF trendingScore 第 6；非今日发布

Unlimited-OCR-2 用稀疏参考滑窗注意力，把跨页读取集中到固定大小的工作参考集合，降低长文档解码的计算和显存增长。

适合研究多页资料解析；部署说明提醒，缩小页窗口会影响跨窗口内容衔接，“无限长度”不代表无限显存或无损解析。

Building Reasoning Models from the Ground Up: A Full Video Course

深度精选 · 2026-10-24 · 8 节视频，逾 11 小时

从预训练的 Qwen3 小模型出发，逐步实现答案验证、采样与多数投票、GRPO 和蒸馏，串起“怎样评估，再怎样改进推理”的完整路径。

早期生成和评估可用 CPU 跟做，训练部分更适合 GPU；需要 Python/PyTorch 基础，不要求先学完上一门课程。

The Paths Perspective on Value Learning

深度精选 · 2019-09-30 · 价值学习的路径视角

从两条轨迹在同一状态交汇的小例子出发，解释时序差分学习怎样复用其他经历中的后续收益，再用同一视角串起 Sarsa、Q-learning 和 Double Q-learning。

图与公式逐步对应，适合建立价值估计的直觉；文章也说明，函数逼近把不该合并的状态混在一起时，误差会被放大。

nesformer

技术博客 · 2026-10-30 · 编译出的神经网络 CPU

nesformer 把 NES 的 6502 CPU 逻辑编译成 Qwen3.5 架构的权重，并把 DeltaNet 状态当作内存；这些权重由编译器计算，未经过训练。

项目展示的是把确定性机器装进神经网络计算图的实验，画面和手柄仍由外部程序处理，运行远慢于真机，也不支持所有卡带。

AI isn't replacing SREs, it's deskilling them 讨论

HN · 过去24小时提交 · 往期原文 2026-02-28

当常见故障都交给 AI，站点可靠性工程师（SRE）还能从哪里练出应对陌生事故的判断力？作者借“自动化的反讽”提出这一风险，并建议保留人工排障练习，让工程师参与分析，而不只是批准机器建议。

这是一篇厂商团队的工程评论，引用其他领域研究作类比，并非已经测得 SRE 技能退化幅度的实证结论。

2026-10-30 · Perri Thaler
