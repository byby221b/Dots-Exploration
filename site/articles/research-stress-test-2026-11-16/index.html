同一组材料换个位置，答案为何会变？

同一个问题、同一组参考材料，只有材料顺序改变，生成答案会不会跟着改变？在检索增强生成（RAG）中，系统先找材料，再把材料交给语言模型作答。若证据已经找到了，却在某些位置用不好，继续改善检索召回未必能解决眼前这一步。

本期审查 Liu 等人的《Lost in the Middle》提出的公开实证主张：在其多文档问答设置中，答案证据所在位置会影响模型表现，许多受测模型在中间位置表现较差。论文正文 §2、§4 与附录给出了受控实验。这是一项建议审查的公开问题，不代表读者正在开展某个项目，也不把旧模型结果当作今天所有模型的定律。

先固定材料，再移动证据

用一个合成例子说明操作。问题是“青岚站周六几点开门？”五张资料卡里，A 明确写着“青岚站周六 09:30 开门”；B 讲另一站的时间，C 讲工作日时间，D 讲位置，E 讲票价。假定 A 是唯一充分证据，其余材料都不含正确答案。这里的站名与时间只用于解释实验。

排列资料顺序改变的条件
证据靠前A → B → C → D → EA 在第 1 张
证据居中B → C → A → D → EA 在第 3 张
证据靠后B → C → D → E → AA 在第 5 张

三种输入使用同一个问题和相同五张卡，不删材料、不改措辞，也不把正确答案提示给模型。B、C、D、E 的相对顺序保持不变。这样，若结果改变，就不能把它解释为“这次检索到了更好的资料”。但移动 A 同时改变了邻接关系和其他卡的绝对位置，因此这仍是整个排列的干预，不能凭一次差异断言某一个注意力头就是原因。

先做这种受控移动，是为了把“信息是否在场”和“模型能否在当前位置使用它”分开。它也有明确边界：这是已知证据位置的诊断实验，真实检索时通常不知道哪张卡正确，不能直接拿人工挑出的 A 排序结果充当可部署收益。

把主张写成能失败的检验

本期的局部假设是：对预先锁定的模型版本、提示模板、单证据问答集和输入长度，将同一证据从前端或后端移到中间，会使正确率下降，且下降超过事先设定的实际关注门槛 δ。δ 是值得采取行动的百分点差，不是从测试结果中挑出的显著数字；它应在看结果前根据错误代价确定。

对第 i 个问题，记前、中、后三种排列的答对情况为 Fᵢ、Mᵢ、Lᵢ：答对取 1，答错取 0。先计算每题差值 dᵢ＝(Fᵢ＋Lᵢ)／2－Mᵢ，再对全部问题求平均，得到 Δ。这样，每个问题都与自己的其他排列比较，困难问题不会因为恰好被分到“中间组”而制造差距。

例如，同一道题前端答对、中间答错、后端答对，dᵢ＝1；三种都对或都错，dᵢ＝0。这只是指标的手算说明，不是实验结果。还要分别报告前端减中间、后端减中间：只看到一个平均差，可能掩盖模型仅偏好末尾的情况。

“中间较差”和“答案不依赖位置”也不是互为完整反面。如果前端差、后端好、中间居中，说明存在位置敏感性，却不支持两端都优于中间的完整 U 形描述。预先区分这些判断，才能避免结果出来后随意换说法。

原文支持什么，哪些结果限制了它

原论文使用 NaturalQuestions-Open 构造单篇答案文档加干扰文档的问答输入，控制证据位置；其附录还检查了随机干扰文档及打乱干扰顺序。所见位置效应因而不能简单归结为检索排序。但这是特定任务与当时模型的证据，不能推出任意长文本任务都遵循同一曲线。来源 1

同一论文里就有最有用的限制证据：某些模型在合成键值检索中接近满分；把问题放在材料前后，对键值检索很有效，却没有同样改善多文档问答；附录中的 Llama-2 7B 主要表现为近因偏好。这些结果直接反对“所有任务和模型都必然中间失效”的泛化，未否定受测问答设置中的位置差异。

后续《Found in the middle》直接处理同一问题：作者估计并校正位置相关的注意力偏差，在 Vicuna 与 Tulu 的问答实验中报告改善。它为可干预的机制提供支持，也说明位置效应并非不可改变。正式会议版 §3–4还把校正与文档重排组合；两者可以互补，不应被包装成必须二选一的路线。

注意力是模型内部给不同输入分配的权重，权重较高与答案引用某段材料之间的相关性，本身不足以确立完整因果解释。校正实验比只画热图更有力，但仍受模型、数据和实现条件限制。本期最先检验可观察的答题变化，不以热图代替正确率，也不声称已经证明了唯一机制。

最低成本实验：先做配对诊断

以下是提案，未执行。先从公开问答数据抽取一份小型开发集检查提示和评分，再锁定另一份测试集。每题人工或按明确标注核对唯一充分证据，剔除答案歧义、材料时点冲突及干扰文档也能合理作答的情况。开发集可用于选提示，测试集不能用来反复挑最有利的排列。

一个便于估算预算的先导设计是 200 道测试题，每题固定 10 篇文档，把证据放在第 1、5、10 位，各生成一次，共 600 次生成；这个数只决定先导规模，不保证统计功效。所有输入必须实际落在模型上下文上限内，留足相同输出额度，检查没有静默截断，并记录证据的 token 偏移。文档序号相同不等于 token 位置相同。

固定模型权重或明确 API 版本、系统提示、问题位置、采样配置、量化方式和服务配置。采用确定性解码时仍记录服务端可能的波动；有随机采样时，各条件使用相同次数的重复生成，不能只给某种排列多次机会。先固定一个干扰顺序，再用少量预先指定的随机顺序复核，避免结论依赖某一对邻居。

对照回答的问题解读限制
只给答案文档有充分证据时能否完成这道题？是诊断参照，材料更短，成本不等同
不给文档是否凭已有知识也能回答？正确不证明使用了所给证据
固定全集，前／中／后移动相同材料下是否存在位置敏感性？主要配对比较
完整材料＋预定重排器不知道答案时，重排能否改善作答？计入重排成本，不能用标准答案排序

原作者公开代码与数据说明提供了证据文档标记和多文档输入，适合把数据构造与评分方式核对清楚。若复用公开数据，需记录其版本和去重方式；公开题可能进入过训练集，因此再看不依赖现实常识的合成材料可帮助诊断，但合成任务通过也不能替代真实问答。

区分归因，再考虑修复

最先排查四个混杂因素：输入是否截断；答案或提示是否因排序而泄露；位置变化是否同时改变文档长度或检索集合；评分是否把冗长回答中偶然出现答案算成正确。评分规则要先锁定，尽量使用简短答案及认可的别名，并抽查语义错误；若使用自动裁判，也要固定版本和评分提示。

若配对差异确实存在，再做单条件消融：保持文档不变，仅将问题从末尾改为前后各出现一次；保持长度和位置设置，比较相关干扰与随机干扰；在能安全访问注意力的公开模型上，才考虑复现校正方法，并配上不校正基线。每项消融单独回答一个解释，不能同时换模型、检索器与提示后把收益全归到位置处理。

文档重排是最近、最容易部署的比较对象。固定候选全集后，使用事先锁定的相关性排序器；它可以与内部注意力校正叠加。压缩材料、增加检索召回和更换更强模型则改变了其他条件，可以另做端到端方案比较，但不能用它们单独证明位置机制。

公平预算需分两张账：机制诊断里，配对条件固定材料和生成次数；工程比较里，把重排、校正预处理、输入输出 token、峰值显存及端到端延迟全部计入。若增加额外调用才能改善正确率，应在同一总调用或时间预算下给基线同等资源，或清楚报告质量—成本曲线，不只比较单次生成耗时。

看到什么结果，应修改判断

主指标是配对差 Δ，同时报告三个位置各自正确率、最差位置正确率、每题答案一致性和成本。以问题为单位重采样，计算 Δ 的置信区间；同一道题的多个排列不能当成互相独立的多道题。先导样本区间很宽时，结论是证据不足，再据方差和关注门槛规划样本量，不能写成“没有位置效应”。

若 Δ 的区间整体高于 δ，且两端各自相对中间都更好，才在这套模型、数据和长度条件下支持值得处理的中间损失。若只有末尾更好，应改成近因偏好的判断。若区间上界已低于 δ，则放弃“本设置存在大到值得处理的中间损失”这一假设；这不等于证明所有位置完全等价。

若差距只在截断输入中出现，先修输入管线；若无文档也答对而来源引用不可靠，需重新评估证据使用；若重排提高平均准确率却让某些位置或题型明显变差，保留分层结果；若新增成本超出预设预算，就缩小工程收益主张。每个停止条件都对应一项可观察结果，而不是预设必须反对论文。

读完可先问自己：把正确资料人为移到第一位后答案变好，是否已经证明线上应该重排？还没有。它说明位置可能值得检查；线上收益还依赖排序器能否找到那篇资料，以及额外成本是否可接受。这正是受控诊断到可用方案之间需要补上的一步。

本期边界：没有运行模型实验；上述门槛与预算是可预先登记的方案。可选地留意，最想先区分的是证据没找全、证据已在却没用好，还是修复成本过高。
