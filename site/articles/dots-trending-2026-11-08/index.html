prometheus/prometheus

⭐+322 · Go · GitHub stars today（非北京时间自然日）

定期从服务拉取指标，用标签组织时间序列，再通过 PromQL 查询和规则触发告警，让系统状态变成可追踪的数据。

适合搭建服务监控、分析负载和延迟变化；仓库附架构、配置与服务发现说明，可作为可观测性系统的学习入口。

dsx-ai-factory/nvke

⭐+123 · Go · GitHub stars today（非北京时间自然日）
